# ADR-002：采用发现、召回与消歧分离的模型流水线

## 状态

已确认。

## 决定

- Qwen3.5-9B 负责全文多模态关键名词发现；
- BGE-M3 负责术语语境召回，并与精确匹配、BM25 和章节多样性共同组成证据包；
- Qwen3-32B 只基于证据包进行含义解释、消歧、同义判定和实体分层。

## 原因

9B 模型适合并行扫描全文及视觉资源；32B 模型按候选术语或候选词组运行，
不按正文块逐项运行，可在保持语义质量的同时控制调用成本。

## 被否决方案

- 直接使用单一大模型逐段完成实体抽取和规范化；
- 让 Qwen3-32B 脱离召回证据，仅根据模型常识定义术语。

## 影响

所有后续关系抽取必须复用 `mention_id → sense_id → entity_id` 映射。
模型 ID、端点、提示词版本、证据引用和调用统计必须进入运行清单。
